# 🧩 Coding Exercises

Solve these in one language first. Then try selected problems in another language to compare syntax and standard libraries.

## Beginner
- [ ] Print a greeting.
- [ ] Add two numbers.
- [ ] Check even or odd.
- [ ] Find the maximum of three numbers.
- [ ] Convert Celsius to Fahrenheit.
- [ ] Calculate factorial.
- [ ] Check whether a number is prime.
- [ ] Reverse an integer.
- [ ] Count vowels in a string.
- [ ] Check whether a string is a palindrome.

## Intermediate
- [ ] Find the second-largest distinct array element.
- [ ] Remove duplicates from a sorted array.
- [ ] Count element frequencies.
- [ ] Find two numbers that add to a target.
- [ ] Find the maximum subarray sum.
- [ ] Rotate an array by k positions.
- [ ] Validate balanced brackets.
- [ ] Merge two sorted arrays.
- [ ] Find the first non-repeating character.
- [ ] Implement binary search.

## Data structure practice
- [ ] Implement stack operations.
- [ ] Implement queue operations.
- [ ] Reverse a linked list.
- [ ] Detect a cycle in a linked list.
- [ ] Find tree height.
- [ ] Perform BFS and DFS.
- [ ] Find the kth largest element.
