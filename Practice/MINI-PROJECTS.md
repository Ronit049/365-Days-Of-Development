# 🛠️ Programming Mini-Projects

Build small, complete projects. Start with a simple version and add features gradually.

| Project | Suggested language | Skills practiced |
|---|---|---|
| Number guessing game | Python / Java | Conditions, loops |
| CLI calculator | Python / C++ | Functions, input validation |
| Student record manager | Java / Python | OOP, collections |
| Expense tracker | Python | Files, data structures |
| Contact book | Python / Java | Maps, CRUD |
| Quiz application | JavaScript | DOM, events |
| Responsive portfolio | HTML / CSS / JS | Layout, responsive design |
| Weather dashboard | JavaScript | Fetch API, JSON |
| Library database | SQL | Schema, joins, constraints |
| REST task API | Python / FastAPI | HTTP, validation, database |
| DSA visualizer | JavaScript | Algorithms, visualization |
| Log analyzer | Python | Files, parsing, automation |

## Project completion checklist
- [ ] Define the problem and intended user.
- [ ] List the first version's features.
- [ ] Choose a language and tools.
- [ ] Build a working minimum version.
- [ ] Validate input and handle errors.
- [ ] Test normal and edge cases.
- [ ] Write a README with setup instructions.
- [ ] Add screenshots or a demo if useful.
- [ ] Record future improvements.
