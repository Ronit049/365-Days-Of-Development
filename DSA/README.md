# 🧠 Data Structures and Algorithms Handbook

## Data structures

| Structure | Main idea | Typical use |
|---|---|---|
| Array / Vector | Indexed sequence | Fast indexed access |
| Linked list | Nodes connected by links | Insertions with known position |
| Stack | Last in, first out | Undo, parsing, monotonic stack |
| Queue | First in, first out | Scheduling, BFS |
| Hash map | Key-value lookup | Frequency counting |
| Set | Unique values | Membership and deduplication |
| Heap | Priority-based access | Top-k and scheduling |
| Tree | Hierarchical nodes | Search and hierarchy |
| Graph | Vertices and edges | Networks and paths |

## Algorithms

- Searching: linear search, binary search
- Sorting: insertion, merge, quick, heap sort
- Traversal: BFS, DFS
- Graph algorithms: topological sort, Dijkstra, disjoint set union
- Optimization: greedy algorithms, dynamic programming
- String processing: frequency, matching, tries

## Common patterns

- Two pointers
- Sliding window
- Prefix sums
- Fast and slow pointers
- Binary search on answer
- Monotonic stack
- Backtracking
- BFS / DFS
- Dynamic programming

## Complexity reminder

| Operation / algorithm | Typical complexity |
|---|---|
| Vector index access | O(1) |
| Linear search | O(n) |
| Binary search | O(log n) |
| Hash lookup | Average O(1) |
| Merge sort | O(n log n) |
| BFS / DFS | O(V + E) |

Actual complexity depends on the data structure and implementation.
