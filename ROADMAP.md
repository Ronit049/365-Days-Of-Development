# 🔄 Daily Development Routine

Consistency matters more than the number of hours.

| Activity | Daily Target |
|---|---:|
| DSA Practice | 1–2 hours |
| Agentic AI / Development | 1–2 hours |
| Project Development | 1 hour |
| Learning & Documentation | 30 minutes |
| GitHub Contribution | Daily |

### Daily Rules

1. Solve at least one DSA problem.
2. Write code instead of only watching tutorials.
3. Push meaningful work to GitHub.
4. Document what you learned.
5. Revise previous concepts.
6. Avoid copying solutions without understanding them.
7. Maintain consistency, even on busy days.
