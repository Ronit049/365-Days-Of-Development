# 🧱 Programming Fundamentals

## 1. How a program works

A program is a set of instructions that a computer executes. A typical development cycle is:

1. Understand the problem.
2. Identify inputs and expected outputs.
3. Design an algorithm.
4. Write code.
5. Compile or interpret it.
6. Test normal and edge cases.
7. Debug and improve it.

## 2. Core building blocks

- **Variables:** named references to values.
- **Data types:** describe the kind of value, such as integer, floating-point number, character, or boolean.
- **Operators:** perform arithmetic, comparison, and logical operations.
- **Conditions:** choose which code runs.
- **Loops:** repeat a block of code.
- **Functions:** package reusable behavior.
- **Data structures:** organize data for efficient operations.

## 3. Pseudocode example

```text
START
  READ number
  IF number is divisible by 2
      PRINT "Even"
  ELSE
      PRINT "Odd"
END
```

## 4. Complexity basics

Big-O describes how an algorithm's resource use grows as input size grows.

| Complexity | Common example |
|---|---|
| O(1) | Array access by index |
| O(log n) | Binary search |
| O(n) | One pass through an array |
| O(n log n) | Efficient comparison sorting |
| O(n²) | Two nested passes over n items |
| O(2ⁿ) | Some exhaustive subset searches |

## 5. Problem-solving checklist

- What are the input constraints?
- Can the input be empty?
- Are duplicates possible?
- Can values be negative?
- What is the expected output for the smallest input?
- Can I explain why my algorithm is correct?
- What are its time and space complexities?

## Exercises

- Find the largest of three numbers.
- Calculate the sum from 1 to n.
- Count digits in an integer.
- Reverse a string.
- Check whether a number is prime.
- Find the second-largest distinct element in an array.
