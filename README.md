# 💻 Programming and Coding Guide

A practical companion to the 365 Days of Development challenge. This pack contains structured notes, examples, exercises, and mini-projects for core programming languages and software engineering skills.

## Learning order

1. Programming fundamentals and problem-solving
2. Python
3. C++
4. Java
5. HTML and CSS
6. JavaScript
7. SQL and databases
8. Data Structures and Algorithms
9. Git, debugging, testing, and clean code

You do not need to master every language at once. Pick one primary language for DSA and one for the project you are currently building.

## How to use each topic

- Read the concept.
- Type the example yourself and run it.
- Change the example and predict the output.
- Solve the exercises without looking at solutions.
- Write a short explanation in your own words.
- Save a working example in the relevant folder.

**Rule:** Understanding and being able to explain a solution is more valuable than collecting code snippets.
