## Overview

This repository documents my **365-day journey toward becoming a stronger software developer and AI engineer**.

The initiative focuses on consistent learning, practical implementation, algorithmic problem-solving, and building real-world applications.

Rather than focusing solely on completing tutorials, I aim to develop a deeper understanding of programming concepts through hands-on experimentation, structured documentation, and continuous improvement.

**Core areas of focus:**

- **Python Engineering:** Programming fundamentals, advanced concepts, automation, APIs, and software development.
- **Data Structures & Algorithms:** Problem-solving patterns, algorithm design, complexity analysis, and interview preparation.
- **Agentic AI:** LLMs, AI agents, tool calling, memory, RAG, and multi-agent architectures.

## Development Methodology

Each development day follows a structured workflow:

1. **Learn:** Study a programming concept, algorithm, or AI engineering topic.
2. **Implement:** Translate theoretical knowledge into working code.
3. **Practice:** Solve relevant problems and test edge cases.
4. **Experiment:** Explore practical applications and technical approaches.
5. **Document:** Record implementations, observations, and key learnings.
6. **Review:** Evaluate progress and define the next learning objective.

### Weekly Review

At the end of each week, I will document:

- Concepts covered
- Problems solved
- Implementations completed
- Technical challenges encountered
- Key takeaways
- Next week's objectives

---

## Engineering Principles

This journey is guided by a few principles:

- **Consistency over intensity:** Sustainable daily progress.
- **Understanding over memorization:** Learn the reasoning behind implementations.
- **Practical development:** Build applications, not just isolated examples.
- **Code quality:** Prioritize readability, maintainability, and testing.
- **Continuous improvement:** Review mistakes and refine previous implementations.
