# 🎯 Goals and Commitments

## North Star

Become a stronger software developer with practical skills in problem-solving, full-stack development, and Agentic AI.

## 365-Day Targets

### Problem Solving
- [ ] Solve 300+ well-understood DSA problems.
- [ ] Learn common patterns instead of memorizing solutions.
- [ ] Revisit difficult problems after a few days.
- [ ] Participate in regular coding contests.

### Software Development
- [ ] Build and deploy 10+ useful projects.
- [ ] Strengthen Python and JavaScript.
- [ ] Build frontend and backend applications.
- [ ] Understand databases, APIs, testing, and authentication.

### AI and Agentic AI
- [ ] Understand LLM fundamentals and prompting.
- [ ] Build a RAG application.
- [ ] Learn tool calling and agent workflows.
- [ ] Build and evaluate multi-agent applications.

### Engineering Practices
- [ ] Use Git branches and meaningful commits.
- [ ] Write clear README files and documentation.
- [ ] Learn Docker and CI/CD fundamentals.
- [ ] Contribute to open-source projects.

### Career
- [ ] Keep resume and portfolio updated.
- [ ] Prepare core CS subjects and interview topics.
- [ ] Practice explaining projects clearly.
- [ ] Apply to relevant internships and opportunities.

## Personal Rules
1. Be consistent, but allow recovery when needed.
2. Understand code before submitting it.
3. Build projects that solve a real problem.
4. Ask questions and learn from feedback.
5. Measure progress monthly, not only daily.
